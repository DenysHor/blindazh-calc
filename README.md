# 🛡️ FortCalc Pro — Інженерний калькулятор фортифікаційних споруд

Автономний інженерно-фортифікаційний веб-додаток (PWA) для польового розрахунку котлованів, захисних перекриттів, силових каркасів, специфікацій матеріалів (BOM) та автоматичної генерації покрокового алгоритму будівництва польових укриттів і бліндажів.

---

## 🚀 Основний функціонал

1. **Динамічний розрахунок параметрів:**
   - Повна проєктна глибина котловану (з урахуванням підлоги, чистої висоти, 1 або 2 накатів колод, демпферного шару ґрунту, мішків із піском і маскувального шару).
   - Розрахунок статичного навантаження на перекриття ($т/м^2$) та сумарної маси покрівлі (в тоннах).
   - Інженерне попередження про ризик зламу або провисання колод при ширині споруди понад 2.5–3.0 м.

2. **Силова схема та планування опор:**
   - **Дворядна асиметрична схема:** адаптована під двоярусні ліжка стандарту NATO ($2.1 \times 0.8\text{ м}$) уздовж однієї зі стін, симетричну лінію опор біля ізніжжя та збереження чистого центрального проходу ($1.8–1.9\text{ м}$).
   - **Центральний поздовжній прогін:** класична симетрична схема для штабів та вузьких споруд.
   - **Однопролітна схема:** для перекритих щілин завширшки до 2.5 м.

3. **Специфікація матеріалів (BOM):**
   - Поштучний та кубатурний розрахунок ($м^3$) круглого лісу (накати, прогони, стійки, одяг крутостей).
   - Кількість піддонів, вологостійких плит OSB-3, рулонів гідроізоляції, мішків із піском, будівельних скоб і цвяхів.
   - Експорт таблиці в буфер обміну (TSV) для прямої вставки в **Google Таблиці** або **Excel**.

4. **Розмітка котловану та земляні роботи:**
   - Розрахунок розмірів і точних діагоналей по дну, по верхній брівці (з укосами під тип ґрунту: пісок, суглинок, глина) та по контуру виносних кілочків ($1.5–2.0\text{ м}$ від брівки).
   - Розрахунок об'єму виїмки ґрунту ($м^3$) за формулою обеліска.

5. **Автоматична технологічна карта будівництва:**
   - Формування покрокового алгоритму зведення (від рекогносцировки до внутрішнього облаштування), який динамічно адаптується під вибрані розміри, глибину та кількість шарів.

6. **Інженерні рекомендації з живучості:**
   - Правила безпеки земляних робіт на глибині $> 3.0\text{ м}$, антисептування та корування деревини, захист від FPV-дронів та скидів (Г-подібний тамбур, протидронова сітка), введення кабелів через герметичні гільзи.

## 🌐 Як розгорнути на GitHub Pages (за 2 хвилини)

1. Створіть новий репозиторій на [GitHub](https://github.com/new) (наприклад, `blindazh-calc`).
2. Завантажте файли з цього каталогу (або виконайте `git push`).
3. Перейдіть у вкладку **Settings** репозиторію -> розділ **Pages** (у лівому меню).
4. У пункті **Build and deployment -> Source** виберіть `Deploy from a branch`.
5. Оберіть гілку `main` (або `master`) та папку `/ (root)`, після чого натисніть **Save**.
6. Через 1–2 хвилини ваш додаток буде доступний за посиланням:
   ```
   https://<ваш-логін-github>.github.io/blindazh-calc/
   ```

## 📱 Встановлення на смартфон (PWA)

Додаток працює без доступу до мережі:
- **Android (Chrome):** відкрийте посилання на сайт -> натисніть меню (три крапки) -> **«Встановити додаток»** або **«Додати на головний екран»**.
- **iOS (Safari):** відкрийте сторінку -> кнопка «Поділитися» -> **«На екран "Початковий"»**.
